# Python for Data Analyst – Learning Journey

This repository contains my daily Python practice and projects as I learn Python for a **Data Analyst** role — starting from zero.

## 🎯 Goal
To become confident in Python for data cleaning, analysis, and visualization, in order to be job-ready for a Data Analyst role.

## 📅 Progress

### Week 1: Python Fundamentals ✅
- **Day 1:** `print()`, quotes, comma, comments
- **Day 2:** Variables and data types (string, integer, float)
- **Day 3:** Operators (`+ - * / %`) and comparison operators (`== != > <`)
- **Day 4:** `input()` and type casting (`int()`)
- **Day 5:** String indexing and slicing
- **Day 6:** String methods (`.upper()`, `.strip()`) and f-strings
- **Day 7:** Mini Project — Simple Calculator (`calculator.py`)
